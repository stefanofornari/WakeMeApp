# Notes — packaging/US-000019

* Merges packaging.macos/US-000019, packaging.windows/US-000020 and packaging.linux/US-000021 (their jpackage installers, auto-start, native secret stores and sleep/wake are listed as deferred in the story; the full text is in the git history). IDs 20 and 21 are retired.
* Linux `mvn package` names the archive `wakemeapp-<version>-linux-app.tar.gz`; the Windows `.bat` and `.cmd` files are assembled with CRLF line endings. Windows execution is deferred to the Windows build: run `wakemeapp.bat` with a relative `--calendar` and a path with spaces, then run `dbg.bat wakemeapp.bat`.
* Verified on Linux with `mvn package`: the archive name and script entries, including CRLF batch files; a packaged-launcher smoke test with a stub Java checked `JAVA_HOME`, paths with spaces, argument forwarding, and the unchanged working directory. The application GUI and Windows scripts still need platform verification.
* Status stays WIP until the package has been built and started on Linux, and the Windows `.bat` launcher has been run.

* macOS bundle (the pom and the assembly of postevpn were the model): `mac-app.xml` builds `WakeMeApp.app` with `Contents/app` laid out as the distribution (same dependency sets, the `.sh` scripts, `conf/logging.properties`), `Contents/MacOS/WakeMeApp` (the launcher), `Info.plist` (version filtered by the assembly: `<filtered>` on that one file, the scripts are never filtered), `PkgInfo` and the icon. No resources plugin and no staging directory were needed. The profile `mac-app` is active on macOS only, because the JavaFX jars are the building platform's.
* The launcher exists because Finder starts an application with no shell environment: it looks for Java with `/usr/libexec/java_home -v 21+`, drops the old `-psn_` argument, shows an alert (osascript) if there is no Java, then runs `wakemeapp.sh`. `LSUIElement=true`: menu bar only.
* The icon is drawn by `tools/make_icon.py` (an alarm clock in the colours of the dialogs) and written as an `.icns` of PNG entries without any macOS tool; Pillow reads it back (all sizes).
* Not verified here (no Mac, no Maven): the profile and the assembly, the launcher on a real Mac (the launcher was run with a stub `java`, `-psn_`, `JAVA_HOME`, path lookup and the no-Java exit), Gatekeeper (the bundle is not signed, README tells how to open it), and that the tray icon of SystemTray shows in the menu bar from an application with `LSUIElement`.
