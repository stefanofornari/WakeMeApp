## notify/US-000005 — Full-Screen Overlay Window

### User Story

```
AS A User
I WANT a full-screen overlay notification when a meeting is about to start
SO THAT I cannot miss the meeting even when deeply focused on other work
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Window Style**: Undecorated, always-on-top, semi-transparent background (e.g., 80% opacity dark)
* **Position**: Covers all screens (multi-monitor aware)
* **Animation**: Fade-in over 300ms
* **Focus**: Does not steal keyboard focus from current app unless user clicks

#### Notes
1. Use JavaFX `StageStyle.TRANSPARENT` with `StageStyle.UNDECORATED`
2. Set `stage.setAlwaysOnTop(true)` and `stage.initModality(Modality.NONE)`
3. Cover all screens: iterate `Screen.getScreens()`, create one stage per screen or single full-screen bounds
4. Background: semi-transparent black (`rgba(0,0,0,0.8)`) with blur effect if supported
5. Content centered: meeting title, countdown, join button, snooze/dismiss buttons
6. Escape key dismisses; clicking background dismisses (configurable)
7. **Overlay displays**: title, start datetime, end datetime, organizer, and join URL (from MeetingNotification record)

### Acceptance Criteria

```gherkin
Scenario: Overlay appears on all monitors
  Given a meeting notification is triggered
  And the user has two external monitors connected
  When the full-screen overlay is shown
  Then an overlay window appears on each monitor
  And each overlay covers the entire screen bounds
  And the overlays are synchronized (same content, same countdown)

Scenario: Overlay does not steal keyboard focus
  Given the user is typing in a text editor
  When the overlay appears
  Then the text editor retains keyboard focus
  And the user can continue typing uninterrupted
  And clicking the overlay brings it to front and focuses it

Scenario: Overlay animation is smooth
  Given the overlay is triggered
  When the window appears
  Then it fades in over 300ms
  And the content is readable immediately
  And no visual artifacts appear during animation

Scenario: Overlay content displays meeting info correctly
  Given a meeting with title "Team Standup" starting in 5 minutes
  And a Teams join URL
  When the overlay is shown
  Then the title "Team Standup" is displayed prominently
  And a countdown shows "04:59" and counts down each second
  And a "Join Meeting" button is visible
  And "Snooze" and "Dismiss" buttons are visible

Scenario: Escape key dismisses overlay
  Given the overlay is visible
  When the user presses the Escape key
  Then the overlay closes with a fade-out animation
  And the notification is marked as dismissed for this meeting
```
