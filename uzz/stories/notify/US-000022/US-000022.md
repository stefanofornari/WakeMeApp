## notify/US-000022 — Command-Line Trigger for Meeting Notification

### User Story

```
AS A User
I WANT to trigger a meeting notification from the command line with meeting details
SO THAT I can test notifications or integrate with external scripts without using the GUI
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **CLI Framework**: picocli 4.x for argument parsing

#### Notes
1. Use picocli 4.x for command-line argument parsing
2. Required arguments: `--title` (meeting title), `--start-date` (ISO-8601 datetime, e.g., "2026-11-03T10:00:00")
3. Optional arguments: `--end-date` (ISO-8601 datetime), `--organizer`, `--url` (join URL), `--description`
4. Parse arguments into a `MeetingNotification` record and trigger the overlay via `OverlayManager`
5. Run on JavaFX Application Thread using `Platform.runLater()`
6. Exit with code 0 on success, non-zero on validation/parsing error
7. Help output via `--help` should show all options with descriptions

### Acceptance Criteria

```gherkin
Scenario: Trigger notification with required arguments only
  Given the application is running
  When the user runs: java -jar app.jar --title "Team Standup" --start-date "2026-11-03T10:00:00"
  Then a full-screen overlay appears with title "Team Standup"
  And the countdown shows time until 2026-11-03T10:00:00
  And the application exits with code 0

Scenario: Trigger notification with all optional arguments
  Given the application is running
  When the user runs: java -jar app.jar --title "Team Standup" --start-date "2026-11-03T10:00:00" --end-date "2026-11-03T11:00:00" --organizer "John Doe" --url "https://teams.microsoft.com/l/meetup-join/..." --description "Weekly team sync"
  Then a full-screen overlay appears with title "Team Standup"
  And the organizer "John Doe" is displayed
  And the end time "11:00" is displayed
  And the description is shown

Scenario: Missing required --title argument shows error
  Given the application is running
  When the user runs: java -jar app.jar --start-date "2026-11-03T10:00:00"
  Then the application prints an error message indicating --title is required
  And exits with non-zero code
  And shows usage help

Scenario: Missing required --start-date argument shows error
  Given the application is running
  When the user runs: java -jar app.jar --title "Team Standup"
  Then the application prints an error message indicating --start-date is required
  And exits with non-zero code
  And shows usage help

Scenario: Invalid --start-date format shows error
  Given the application is running
  When the user runs: java -jar app.jar --title "Team Standup" --start-date "invalid-date"
  Then the application prints an error message indicating invalid date format
  And exits with non-zero code
  And shows usage help

Scenario: Help flag shows usage information
  Given the application is running
  When the user runs: java -jar app.jar --help
  Then the application prints usage with all options and descriptions
  And exits with code 0
```
