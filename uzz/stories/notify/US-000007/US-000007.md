## notify/US-000007 — One-Click Join Button

### User Story

```
AS A User
I WANT a "Join Meeting" button in the notification that opens the Teams meeting URL
SO THAT I can join the meeting with a single click without searching for the link
```

#### Dependencies

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Action**: `Desktop.getDesktop().browse(joinUrl.toURI())` or platform-specific browser launch
* **URL Source**: `CalendarEvent.joinUrl` (carried from the calendar source: calendar/US-000028, calendar/US-000003)
* **Fallback**: Copy URL to clipboard if browser launch fails
* **Visual**: Prominent button, primary color, "Join Meeting" label with Teams icon

#### Notes
1. Validate URL before launching (must be http/https)
2. Prefer system default browser
3. On macOS, `open` command can target specific browser if configured
4. Track join action for analytics (optional)
5. Close overlay after successful launch (configurable)
6. Handle meeting URLs that redirect (Teams web → Teams app)

### Acceptance Criteria

```gherkin
Scenario: Join button opens Teams meeting in default browser
  Given a notification overlay is shown for a Teams meeting
  And the meeting has a valid joinUrl (https://teams.microsoft.com/l/meetup-join/...)
  When the user clicks "Join Meeting"
  Then the system default browser opens the join URL
  And the overlay closes (if configured)

Scenario: Join button works with Teams app deep link
  Given a notification overlay is shown
  And the joinUrl is a Teams deep link (msteams://...)
  When the user clicks "Join Meeting"
  Then the Teams desktop app launches and joins the meeting
  And the overlay closes

Scenario: Fallback to clipboard on browser launch failure
  Given a notification overlay is shown
  And the browser launch fails (no default browser, permission denied)
  When the user clicks "Join Meeting"
  Then the join URL is copied to system clipboard
  And a toast notification appears: "Meeting link copied to clipboard"
  And the overlay remains open

Scenario: Join button disabled for meetings without URL
  Given a notification overlay is shown for a non-online meeting (no join URL)
  When the overlay is rendered
  Then the "Join Meeting" button is hidden or disabled
  And only "Snooze" and "Dismiss" buttons are shown

Scenario: Join button visual feedback
  Given the overlay is visible
  When the user hovers over "Join Meeting"
  Then the button shows hover state (color change, cursor pointer)
  When the user clicks the button
  Then the button shows pressed state briefly
  And the launch action is triggered
```
