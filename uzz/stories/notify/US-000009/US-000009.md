## notify/US-000009 — Snooze Options

### User Story

```
AS A User
I WANT to snooze a meeting notification for a specific duration
SO THAT I can finish my current task before joining the meeting
```

TODO

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Snooze Durations**: 1 minute, 5 minutes, 10 minutes, "Until meeting starts"
* **Behavior**: Close overlay, schedule re-notification at snooze end time
* **Max Snoozes**: Configurable limit (default: 3 per meeting)
* **Display**: Show snooze count in overlay ("Snoozed 2/3 times")
* **Until Meeting Starts**: Calculates exact time until meeting start, re-notifies at 1 min before

#### Notes
1. Snooze state persisted in memory (survives app restart via scheduler)
2. Each snooze creates a new scheduled task in scheduler/US-000011
3. "Until meeting starts" = meetingStart.minusMinutes(1)
4. Disable snooze buttons if max reached
5. Snooze from tray/menu bar also supported (scheduler/US-000012)

### Acceptance Criteria

```gherkin
Scenario: Snooze for 5 minutes closes overlay and re-notifies
  Given a meeting notification overlay is visible
  And the meeting starts in 15 minutes
  When the user clicks "Snooze 5 min"
  Then the overlay closes with fade-out
  And a notification is scheduled for 5 minutes from now
  And when the snooze time elapses, the overlay reappears
  And the countdown shows 10 minutes remaining (original meeting time)

Scenario: Snooze "Until meeting starts" calculates correct time
  Given a meeting notification overlay is visible
  And the meeting starts in 8 minutes
  When the user clicks "Until meeting starts"
  Then the overlay closes
  And a notification is scheduled for 7 minutes from now (1 min before meeting)
  And when it triggers, the countdown shows "01:00"

Scenario: Snooze count is tracked and limited
  Given the max snoozes per meeting is 3 (default)
  When the user snoozes a meeting 3 times
  And the 4th notification appears
  Then the snooze buttons are disabled/hidden
  And only "Join Meeting" and "Dismiss" are available
  And the overlay shows "Snoozed 3/3 times"

Scenario: Snooze persists across app restart
  Given a meeting is snoozed for 10 minutes
  And the user quits and restarts the app within that 10 minutes
  When the app restarts
  Then the snooze schedule is restored from persisted state
  And the notification triggers at the correct time

Scenario: Snooze from menu bar
  Given a meeting notification was dismissed but a snooze is active
  And the app is running in menu bar (scheduler/US-000012)
  When the user clicks the menu bar icon
  Then the menu shows "Snoozed: Team Standup (3 min remaining)"
  And a "Snooze 5 min" option is available in the menu
  And clicking it extends the snooze
```
