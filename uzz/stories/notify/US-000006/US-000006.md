## notify/US-000006 — Countdown Timer

### User Story

```
AS A User
I WANT to see a live countdown to the meeting start time in the notification
SO THAT I know exactly how much time I have left to prepare
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Update Frequency**: Every second
* **Format**: MM:SS (switch to HH:MM:SS if > 1 hour)
* **Color Coding**: Green (>5 min), Yellow (1-5 min), Red (<1 min), Flashing (past start)
* **Synchronization**: Countdown based on system clock, not timer accumulation (drift-free)

#### Notes
1. Use `java.time.ZonedDateTime` for meeting start time
2. Calculate remaining duration on each tick: `Duration.between(now, meetingStart)`
3. Update UI on JavaFX Application Thread via `Platform.runLater()`
4. Stop timer when meeting starts (show "Meeting started" or "Join now")
5. Handle snooze: reset countdown to snooze duration

### Acceptance Criteria

```gherkin
Scenario: Countdown displays correct format for different time ranges
  Given a meeting starting in 15 minutes
  When the overlay is shown
  Then the countdown displays "15:00" (MM:SS format)

  Given a meeting starting in 1 hour 30 minutes
  When the overlay is shown
  Then the countdown displays "01:30:00" (HH:MM:SS format)

Scenario: Countdown updates every second without drift
  Given the overlay is visible with a countdown
  When 10 seconds of real time elapse
  Then the countdown has decreased by exactly 10 seconds
  And no cumulative drift occurs over extended periods

Scenario: Color coding changes at thresholds
  Given a meeting starting in 6 minutes
  When the overlay is shown
  Then the countdown text is green

  Given the countdown reaches 4:59
  Then the countdown text changes to yellow

  Given the countdown reaches 0:59
  Then the countdown text changes to red

  Given the countdown reaches 0:00 (meeting started)
  Then the countdown text flashes red/white
  And the text changes to "Meeting started - Join now"

Scenario: Countdown pauses/resumes correctly with snooze
  Given a meeting in 10 minutes with active countdown
  When the user clicks "Snooze 5 min"
  Then the countdown resets to "05:00"
  And resumes counting down from 5 minutes
  And the original meeting start time is preserved for "Join" action
```
