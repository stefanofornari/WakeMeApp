## scheduler/US-000012 — System Tray / Menu Bar Icon

### User Story

```
AS A User
I WANT a menu bar icon (macOS) or system tray icon (Windows/Linux)
SO THAT I can see the app status, access upcoming meetings, and control notifications without opening the main window
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **macOS**: `NSStatusItem` via JNI/JNA or JavaFX `SystemTray` (limited)
* **Windows/Linux**: JavaFX `SystemTray` API
* **Icon**: Template image (monochrome) for macOS dark/light mode support
* **Menu Items**: Show/Hide Window, Upcoming Meetings (submenu), Snooze Active, Settings, Quit
* **Tooltip**: "WakeMeUp - Next: Team Standup in 5 min"

#### Notes
0. The icon itself, the "Settings…" and "Quit" items come from settings/US-000054 (FXTrayIcon, all platforms); this story adds the rest of the menu. Notes 1-3 below on JNI/`NSStatusItem` are superseded by FXTrayIcon.
0. A dismissed meeting (notify/US-000010) is not shown in the upcoming list; `DismissedMeetings.isDismissed(eventId, start)` tells which.
1. Use library like `com.github.weisj:darkmode` or custom JNI for native macOS menu bar
2. JavaFX `SystemTray` is cross-platform but limited on macOS (no menu bar support in older versions)
3. For macOS, consider embedding a Swift helper or using `jnidispatch` for `NSStatusItem`
4. Menu updates dynamically based on scheduler state
5. Click icon: toggle main window visibility
6. Right-click: show context menu

### Acceptance Criteria

```gherkin
Scenario: Menu bar icon appears on macOS launch
  Given the app is launched on macOS
  When the app starts
  Then a menu bar icon appears in the top-right status bar
  And the icon uses template rendering (adapts to dark/light mode)
  And the tooltip shows "WakeMeUp - Ready"

Scenario: Click toggles main window
  Given the menu bar icon is visible
  And the main window is hidden
  When the user clicks the menu bar icon
  Then the main window appears and gains focus
  When the user clicks the icon again
  Then the main window hides

Scenario: Menu shows upcoming meetings with countdown
  Given the scheduler has meetings at 10:00 AM and 11:00 AM
  And current time is 9:50 AM
  When the user right-clicks the menu bar icon
  Then the context menu shows:
    | Menu Item                    |
    | Show Window                  |
    | ---                          |
    | Team Standup - 10:00 (10 min)|
    | Project Review - 11:00 (70 min)|
    | ---                          |
    | Snooze Active: None          |
    | Settings...                  |
    | Quit                         |

Scenario: Active snooze shown in menu with controls
  Given "Team Standup" is snoozed for 5 minutes (3 min remaining)
  When the user opens the menu bar menu
  Then the menu shows "Snooze Active: Team Standup (3 min)"
  And a submenu "Extend Snooze" with 1/5/10 min options
  And a "Cancel Snooze" option

Scenario: Menu bar updates in real-time
  Given the menu is open
  When a new meeting enters the lead time window
  Then the menu updates to show the new meeting
  And countdown timers update every minute
  Without requiring menu re-open

Scenario: Quit from menu bar stops app completely
  Given the app is running in menu bar
  When the user selects "Quit" from the menu
  Then the scheduler shuts down (scheduler/US-000011)
  And the menu bar icon is removed
  And the JVM exits cleanly
```
