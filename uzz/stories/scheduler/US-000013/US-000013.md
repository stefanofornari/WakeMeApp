## scheduler/US-000013 — Auto-Start at Login

### User Story

```
AS A User
I WANT the app to start automatically at login
SO THAT I'm always protected from missing meetings without manual intervention
```

#### Dependencies
- scheduler/US-000011

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **macOS**: Launch Agent (`~/Library/LaunchAgents/com.wakemeup.plist`)
* **Windows**: Registry Run key or Startup folder shortcut
* **Linux**: `~/.config/autostart/wakemeup.desktop`
* **UI**: Checkbox in Settings (settings/US-000014)
* **Behavior**: Launch hidden (menu bar only), no main window
* **Permission**: Request user consent before installing

#### Notes
1. macOS Launch Agent runs as user (not root), survives reboot
2. Java app needs wrapper script or `java -jar` in plist
3. Handle Java runtime location (bundled JRE vs system Java)
4. Provide uninstall/remove option in settings
5. Test on clean login to verify no UI flashes

### Acceptance Criteria

```gherkin
Scenario: Auto-start enabled creates launch agent on macOS
  Given the user checks "Start at login" in settings
  And the app is not currently set to auto-start
  When the user saves settings
  Then a Launch Agent plist is created at ~/Library/LaunchAgents/com.wakemeup.plist
  And the plist contains correct ProgramArguments (java -jar /path/to/wakemeup.jar)
  And the plist has RunAtLoad = true
  And launchctl loads the agent

Scenario: Auto-start disabled removes launch agent
  Given auto-start is currently enabled
  When the user unchecks "Start at login" and saves
  Then the Launch Agent is unloaded via launchctl
  And the plist file is deleted
  And no auto-start occurs on next login

Scenario: App launches hidden on login
  Given auto-start is enabled
  And the user logs into macOS
  When the Launch Agent starts the app
  Then the app starts without showing the main window
  And the menu bar icon appears (scheduler/US-000012)
  And the scheduler begins polling (scheduler/US-000011)
  And no dock icon bounces or appears

Scenario: Auto-start works with bundled JRE
  Given the app is packaged with jpackage (macOS .dmg/.pkg)
  And auto-start is enabled
  When the user logs in
  Then the Launch Agent uses the bundled Java runtime
  And the app starts successfully without system Java installed

Scenario: Settings UI reflects current auto-start state
  Given auto-start is enabled via previous session
  When the user opens Settings
  Then the "Start at login" checkbox is checked
  And unchecking it disables auto-start immediately
```
