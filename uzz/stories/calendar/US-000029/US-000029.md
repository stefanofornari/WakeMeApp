## calendar/US-000029 — Notify Only for Relevant Meetings

### User Story

```
AS A User
I WANT to be notified only for meetings I attend or may attend
SO THAT I am not interrupted by events that do not need me
```

#### Dependencies
- calendar/US-000028

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Phase**: all-day events are excluded for now and tracked as a future feature

#### Notes
1. Included: accepted (committed), tentative and meetings the user organises.
2. Excluded: all-day events, declined meetings, meetings the user has not answered.
3. The filter is applied to the meetings returned by the calendar source before they reach the scheduler; it relies on the response status and all-day flag of the meeting data.

### Acceptance Criteria

```gherkin
Scenario: Accepted and tentative meetings are scheduled
  Given the calendar source has an accepted meeting and a tentative meeting within the window
  When the poller runs
  Then both meetings are scheduled

Scenario: A meeting organised by the user is scheduled
  Given a meeting within the window organised by the user
  When the poller runs
  Then the meeting is scheduled

Scenario: Declined and unanswered meetings are ignored
  Given a declined meeting and an unanswered meeting within the window
  When the poller runs
  Then neither meeting is scheduled

Scenario: All-day events are ignored
  Given an all-day event on today's date
  When the poller runs
  Then the event is not scheduled
```
