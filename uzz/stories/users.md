# Users

Actors referenced by the `AS A [role]` clause of user stories. This list is
authoritative: stories must not invent roles that are not listed here. Add a
role only when the project genuinely has it.

- **User**: The person using WakeMeUp to receive attention-grabbing meeting notifications for their Outlook/Teams calendar. They configure the app once and expect it to run in the background.
- **System**: The automated background scheduler that polls Microsoft Graph and triggers notifications when meetings are approaching.
