## logging/US-000035 — Also Log to the Console

### User Story

```
AS A User
I WANT the same log messages on the console where I started the application
SO THAT I see what happens while I run it from a terminal
```

#### Status
WIP

#### Dependencies
- logging/US-000034

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Logging**: `java.util.logging` `ConsoleHandler` (stderr), same formatter and level as the file handler

#### Notes
1. Same one-line format as the file (logging/US-000034).
2. Console output goes to stderr, like any log; stdout is left to the program's own output (help, version).
3. When the log file cannot be used, the console is the only destination.

### Acceptance Criteria

```gherkin
Scenario: Messages appear on the console and in the file
  When the application logs "Polling meetings.csv every 5 min" at INFO
  Then the same line is written to the console
  And to the log file

Scenario: The console follows the same level
  Given the application runs at level INFO
  When it logs a DEBUG message
  Then the message is on neither the console nor the file

Scenario: Without a usable log file the console still shows the messages
  Given the log file cannot be used
  When the application logs a message
  Then it appears on the console
```
