## settings/US-000057 — Set the Calendar in the Settings Dialog

### User Story

```
AS A User
I WANT to type my calendar (ICS link, Outlook address or CSV file) in one field of the settings dialog
SO THAT the application polls it without me touching the command line
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (all platforms; macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Field**: one text field; the kind is detected as for `--calendar`: ICS link, then Graph address, then CSV file path (calendar/scope.md)
* **Detected kind**: shown next to the field ("ICS link", "Microsoft Graph address", "CSV file")
* **Validation on Save**: ICS link `https://` or `webcal://` (plain `http://` refused); Graph address on graph.microsoft.com; CSV path an existing readable file
* **Masking**: after saving, an ICS link is shown as `https://host/…`; to change it the user types the whole value again; no reveal

#### Notes
1. A value that fits none is refused with a message naming the three accepted forms; the message never echoes a link.
2. Saving writes the value with settings/US-000055 and applies it at once: the poller is restarted on the new calendar, the exclamation mark of the tray icon (settings/US-000054) clears.
3. Saving an empty field removes the stored value; the tray icon shows the exclamation mark again and polling stops.
4. For a Graph address the dialog tells the user that the Microsoft account section is needed (settings/US-000014); for the other kinds that section is ignored.
5. Choosing a CSV file with a file picker is not in this story: the path is typed or pasted.

### Acceptance Criteria

```gherkin
Scenario: Saving an ICS link starts polling it
  Given the dialog is open and no calendar is configured
  When the user types a valid https link and clicks "Save"
  Then the kind shown is "ICS link"
  And the calendar is polled
  And the tray exclamation mark disappears

Scenario: The saved link is masked
  Given an ICS link was saved
  When the dialog is opened again
  Then the field shows "https://outlook.office365.com/…"

Scenario: A plain http link is refused
  When the user saves "http://example.com/calendar.ics"
  Then an error says that the link must start with https or webcal
  And nothing is stored

Scenario: A missing file is refused
  When the user saves the path of a CSV file that does not exist
  Then an error says the file cannot be read
  And nothing is stored

Scenario: A value of no known kind is refused without echoing it
  When the user saves "hello"
  Then an error names the three accepted forms
  And the message does not contain "hello" if it looks like a link

Scenario: A Graph address asks for the Microsoft account
  When the user saves a graph.microsoft.com address
  Then the kind shown is "Microsoft Graph address"
  And a hint says that client ID and tenant are needed

Scenario: Emptying the field removes the calendar
  Given a calendar is stored
  When the user empties the field and saves
  Then the stored value is removed
  And the tray icon shows the exclamation mark
```
