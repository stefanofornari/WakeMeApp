## settings/US-000054 — Start in the Tray

### User Story

```
AS A User
I WANT the application, started without arguments, to live in the tray / menu bar
SO THAT it runs quietly, and I can see at a glance whether it still needs a calendar
```

#### Technical Context & Constraints
* **Target System**: JavaFX desktop app (all platforms; macOS primary)
* **Toolchain / Rules**: Maven + JavaFX 25 + Java 25
* **Library**: FXTrayIcon (https://github.com/dustinkredmond/FXTrayIcon), one new dependency; JavaFX and the library provide the native tray on macOS, Windows and Linux (settings/scope.md)
* **Menu**: "Settings…" and "Quit" only; the richer menu (upcoming meetings, snooze, enable/disable) stays in scheduler/US-000012
* **Icons**: normal icon and a variant with an exclamation mark, both bundled in the JAR

#### Notes
1. Started with no arguments the application shows no window; with `--calendar` it keeps working as today and also shows the tray icon.
2. "No calendar configured" means no `--calendar` and no stored calendar value (settings/US-000055 provides the stored value; until then only the command line can configure it).
3. The tooltip for the unconfigured state: "WakeMeApp - no calendar configured".
4. "Settings…" is disabled until settings/US-000056 exists; Quit calls the application-level shutdown of scheduler/US-000025.
5. Where the platform has no tray (some Linux desktops) the application says so in the log and keeps running; it does not fail.
6. scheduler/US-000012 builds on this icon (menu items, upcoming meetings, tooltip with the next meeting); its notes about JNI and `NSStatusItem` are superseded by FXTrayIcon.

### Acceptance Criteria

```gherkin
Scenario: Started without arguments the app lives in the tray
  Given the application is started with no arguments
  Then a tray icon is shown
  And no window is shown
  And the process stays alive

Scenario: Not configured shows the exclamation mark
  Given no calendar is configured
  When the application starts
  Then the tray icon carries an exclamation mark
  And its tooltip is "WakeMeApp - no calendar configured"
  And nothing is polled

Scenario: Configured shows the normal icon
  Given a calendar is configured
  When the application starts
  Then the tray icon has no exclamation mark
  And the calendar is polled

Scenario: The mark clears when a calendar is saved
  Given the icon carries the exclamation mark
  When a calendar value is saved
  Then the exclamation mark disappears without a restart
  And polling starts

Scenario: Quit ends the application
  When the user chooses "Quit" in the tray menu
  Then pending notifications are cancelled and the application ends

Scenario: No tray on the desktop
  Given the platform offers no system tray
  When the application starts
  Then a message in the log says the tray is not available
  And the application keeps running
```
