## settings/US-000044 — Document How to Inspect the Stored Settings

### User Story

```
AS A User or a Support Person
I WANT to know how to see the settings the application has stored on my operating system
SO THAT I can check and fix a configuration without guessing where it is
```

#### Technical Context & Constraints
* **Target System**: macOS, Windows, Linux
* **Deliverable**: a markdown page `docs/settings.md`, linked from the project README when there is one
* **Node**: `/ste/wakemeapp` in the user Preferences (see settings/scope.md)

#### Notes
1. Per platform: what store is used, the exact command or tool to read the values, and how to remove them (reset to defaults).
   - macOS: plist `~/Library/Preferences/com.apple.java.util.prefs.plist`; read with `defaults read com.apple.java.util.prefs`, or `plutil -p`; read through `defaults`, not the file, because macOS caches preferences.
   - Windows: registry `HKCU\Software\JavaSoft\Prefs\ste\wakemeapp`; `reg query`, or regedit.
   - Linux: XML `~/.java/.userPrefs/ste/wakemeapp/prefs.xml`.
2. Every command is run on the platform before it is written down; the macOS ones are not verified yet.
3. The page also documents `--print-config` as the same-on-every-platform way, and the list of keys with meaning and default.
4. It states that the token cache is not in Preferences and where it is (application data directory).

### Acceptance Criteria

```gherkin
Scenario: Each platform has an inspect command
  Given the page docs/settings.md
  Then it has a section for macOS, Windows and Linux
  And each section gives the location of the stored values and a command that prints them

Scenario: The commands were checked
  Given the application has stored a setting
  When each documented command is run on its platform
  Then the stored value is shown

Scenario: Reset is documented
  Given the page docs/settings.md
  Then each platform section says how to delete the stored values

Scenario: The keys are listed
  Given the page docs/settings.md
  Then every stored key is listed with its meaning and default
  And the page says where the token cache is, and that it is not in Preferences
```
